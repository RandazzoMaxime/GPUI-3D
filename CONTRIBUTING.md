# Contributing

This repository accepts contributions **from forks only**.

## What to do

1. [Fork](https://github.com/RandazzoMaxime/GPUI-3D/fork) the repository.
2. Create a branch **on your fork** (never on this repository).
3. Open a pull request against `main`.
4. Wait for the maintainer to review and merge.

By opening a pull request, you license your contribution under [0BSD](LICENSE), same as the original GPUI-3D code.

## What GitHub blocks on this repository

A ruleset is active on every branch. Only the owner can:

- create a branch here
- push commits here
- merge a pull request

Everyone else works on a fork and opens a PR. That is the whole workflow.
